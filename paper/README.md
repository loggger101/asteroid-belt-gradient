# The paper

**`main.tex` (with `refs.bib`) is the paper.** Edit it directly and compile it in this folder:

```bash
latexmk -pdf main.tex
```

That needs a TeX distribution with pdfLaTeX, BibTeX and latexmk (TeX Live, MiKTeX or TinyTeX). The figures
are not copied here: `\graphicspath{{../}}` makes `figures/...` the repository's own `figures/`, the files
`belt-gradient run` writes, so a rerun of the analysis is picked up at the next compile. Build products
(`main.pdf`, `.aux`, `.log`, ...) are git-ignored; CI compiles the paper on every pull request and push to
main and attaches `main.pdf` to the run (workflow `paper.yml`, artifact `paper-pdf`).

When the analysis changes, cut a new release of the code and cite it: the version appears in Section 3,
in Data availability and in the `edwards2026a` entry of `refs.bib`, and must equal `__version__`.

This folder is AASTeX 7.0.1 (`aastex701.cls`, `aasjournalv7.bst` from CTAN, included): two-column AAS layout,
natbib author-year citations, `refs.bib` (86 entries with DOIs), floating figures, `deluxetable` tables,
appendix figure A1. The paper uses `aasjournalv7tie.bst`, a renamed copy of `aasjournalv7.bst` with one
change (its header says which): in-text citations tie the initials to the surname, so "D. Nesvorný" is
never split across two lines. The original is kept, unchanged.

## Formatting check

After every edit, run `python -I check_format.py` here (it needs `pypdfium2`, compiles in a temporary
folder and never writes into `paper/`; if Python cannot find latexmk, compile with `latexmk -pdf main.tex`
and pass `--build-dir .`). Any FAIL must be fixed. Until the cited version is tagged, the missing tag is a
FAIL; `--untagged-ok` makes it a WARN, which CI uses because the tag is made after the merge. It checks
the standards set by the formatting audit of 2026-10-09/10:

- math as real math (`$D \geq 10$~km`), never `\textsubscript`, `\textless` or `\ensuremath{\geq}` fragments;
  label subscripts upright (`e_{\mathrm{P}}`)
- "au", not "AU"; `~` between a number and its unit
- `Figure~\ref{fig:N}`, `Section~\ref{sec:4.6}`, `Equation~(\ref{eq:1})`: no hard-coded numbers; every
  `\ref` resolves; every figure and table is cited, in numerical order
- a citation in a heading wrapped in `\texorpdfstring`; organisation authors cited with `\citetalias`
- American spelling; no first person
- tables: intervals `[lo, hi]`, thousands separators
- figures: `\columnwidth` (or 3.3125in) in `figure`, `\textwidth` in `figure*`; `\graphicspath{{../}}`
  set, and every included file present in the repository's `figures/`
- abstract at most 250 words; keywords through the class's `\uat{Term}{id}` (links to the UAT)
- names: `aasjournalv7tie` keeps initials with surnames; every plain-ASCII surname in refs.bib is in the
  `\hyphenation` list (add new ones when a reference is added); in the PDF, no initials split from a
  surname and no hyphenated surname
- no loose lines: main.tex sets `\hbadness=1000` (the class sets 10000, which hides them), and any
  "Underfull \hbox" in the log FAILs. Fix one by rewording or moving a long unbreakable chunk (a citation,
  a URL); a paragraph made of URLs and identifiers is set `\raggedright` (Data availability)
- journal names as AASTeX macros (`\apj`) or ADS abbreviations; the cited code release the same in
  main.tex, refs.bib and the repo, and tagged
- a clean build: no undefined references or citations, no overfull lines, no BibTeX warnings; in the PDF,
  no line break between a number and its unit, "Figure" and its number, or around a relation sign
- no class letter split from its word at a line end ("S-/like", "K-/and L-types"): TeX breaks after any
  explicit hyphen, so a suspended hyphen is written `\mbox{K-}~and` (a tie alone does not hold) and a class
  name that breaks is written `\mbox{S-like}` (`\nobreakdash` needs amsmath, which the class does not load)
- no em dashes, typed or generated by the class (`\tablecomments` is redefined to print "Note.")

A WARN means a float lands more than three pages after its first mention. Since 2026-10-10 none does:
a `figure*` or `deluxetable*` can appear at the earliest at the top of the page after the one its source
falls on, so the wide Figure 4 and Table 2 are defined in Section 3.5, a page before Section 4 cites them.
Without that, Figures 4 and 5 and Tables 2 and 3 all piled onto one page with six lines of text. When text
is added or cut, recheck where the floats land. A heading line break is written `\\*`, never `\\` (in a
centered heading `\\` ends a paragraph, and the heading can split across columns).
The check does not replace looking at the rendered pages that changed.

## History

The paper moved into this repository on 2026-10-10. It was created on 2026-10-09 from the earlier Word draft and verified against it (text, every number, link,
reference and figure). The Word draft, its LaTeX copy in the Word layout and the conversion scripts were
deleted the same day, once the AASTeX file became the only version.
